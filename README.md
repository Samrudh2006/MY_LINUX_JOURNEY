## 🌟 Executive Overview

**LINUX SOC & ADVANCED ANALYST HANDBOOK** is a state-of-the-art, interactive **Blue Team Security Operations Platform**. Designed specifically for cybersecurity professionals, SOC Analysts (Tier 1 to Tier 3), DFIR responders, and Linux security enthusiasts, this platform seamlessly bridges fundamental OS mechanics with high-level threat hunting in a unique **Telugu-English bilingual format**.

```
   ┌─────────────────────────────────────────────────────────────────────────┐
   │ 🐧 CINEMATIC BOOT SEQUENCE  ➜  365-PAGE LINUX HANDBOOK  ➜  456-PAGE ADV  │
   │ 💻 LIVE TERMINAL SIMULATOR  ➜  200+ INTERVIEW Q&A  ➜  MITRE ATT&CK LABS │
   └─────────────────────────────────────────────────────────────────────────┘
```

## 🎬 Cinematic Startup Experience

When the application loads, users are greeted with an integrated **Cinematic Boot Sequence** depicting Tux in a high-tech Security Operations Center (SOC).

- **Zero Layout Shift**: Responsive full-viewport (`100dvh`) overlay with `#060911` cyber background.

## 🚀 Quick Start — Running Locally

### Option 1: Using Node.js

```bash
# Clone the repository
git clone https://github.com/Samrudh2006/MY_LINUX_JOURNEY.git

# Navigate into project directory
cd MY_LINUX_JOURNEY

# Start local server
node server.js
```

Then open your browser and navigate to:
```
http://localhost:8086
```

### Option 2: Using Python HTTP Server

```bash
python -m http.server 8086
```
