# LINUX SOC HANDBOOK — 365-Page Linux & SOC Master Platform

> **Built by Samrudh | Telugu-English Interactive Learning Platform**

A complete, interactive **Linux + SOC Analyst** educational platform featuring:

- 📖 **365 Deep-Dive Learning Pages** covering Linux Fundamentals → Threat Hunting → Forensics
- 🎯 **200+ Real-World Interview Q&A** with Telugu-English explanations
- 🛡️ **SOC Workflows, MITRE ATT&CK, SIEM/EDR, Incident Response**
- 💻 **Live Terminal Simulator** (kali@soc-workstation)
- 📱 **Fully Mobile Responsive** — works on phone, tablet, and desktop
- 🌙 **Cyber Dark Mode** + Ruled Notebook Light Mode
- ⌨️ **Keyboard Navigation** (← → arrows, Spacebar auto-play, B for sidebar)
- 🔖 **Bookmarks & Search** across all 365 pages
